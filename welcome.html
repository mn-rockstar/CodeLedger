CodeLedger

Code it. Commit it. Track it.

1

Pin CodeLedger to your toolbar

Click the 🧩 puzzle-piece icon at the top right of your browser, find CodeLedger, and click the pin beside it — so the dashboard is always one click away.

2

Connect your GitHub account

Click the CodeLedger icon and choose Login with GitHub, then create a new private repository or link one you already have.

3

Go solve something

Submit any problem on leetcode.com. The moment it's Accepted, your code and the problem statement land in your repo under 0001-two-sum/.

The first time, it asks you to confirm which LeetCode account is yours, so nothing is committed from an account you didn't mean to use.

Your GitHub token stays on this device and is never sent anywhere except GitHub.
